Comment ça marche

  1. 1
    Préparer le corpus

    Chunks JSONL + métadonnées (titre, URL, type de source) pour traçabilité dans l’UI.

  2. 2
    Indexer

    Embeddings multilingues puis index FAISS (cosinus / produit scalaire selon normalisation).

  3. 3
    Interroger

    L’utilisateur pose une question ; le backend assemble contexte + sources et appelle le LLM configuré.
