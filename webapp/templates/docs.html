Parcours utilisateur (navigateur)

  1. Accueil public puis Connexion (ou inscription si activée).
  2. Accès à l’Assistant : conversation, paramètre k (nombre de passages), panneau Sources à droite.
  3. Nouvelle conversation : réinitialise l’historique côté navigateur (les messages déjà envoyés ne sont plus renvoyés au serveur).

API REST

Toutes les routes ci-dessous attendent du JSON pour POST sauf mention contraire.

POST /api/auth/login

Obtenir un JWT (clients hors navigateur : Streamlit, scripts, mobile).

curl -s -X POST http://127.0.0.1:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"demo","password":"demo123"}'

GET /api/me

Profil utilisateur — en-tête Authorization: Bearer <token>.

POST /api/ask

Interroge le pipeline RAG. Corps JSON : question, top_k (1–20), history (liste optionnelle de {"role":"user|assistant","content":"..."}).

curl -s -X POST http://127.0.0.1:8000/api/ask \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"question":"Quels documents pour le passeport ?","top_k":5,"history":[]}'

GET /health

Sonde l’API ({"status":"ok"}) — utile pour load balancer ou monitoring.

Reconstruction de l’index

Après modification de data/processed/final_chunks.jsonl :

python scripts/build_embeddings.py
python scripts/build_faiss.py

Puis redémarrer uvicorn pour recharger le pipeline en mémoire.
