Confidentialité & données

Ce document décrit le traitement des données dans une instance auto-hébergée type démonstration. Adaptez-le si vous déployez en entreprise ou auprès du public.

Données de navigation

Le site utilise des sessions signées (cookie) pour maintenir la connexion à l’interface web. Les JWT émis par /api/auth/login sont destinés aux clients API et doivent être conservés côté client de façon sécurisée.

Questions posées à l’assistant

Les messages sont envoyés au backend pour retrieval et génération. Ils peuvent apparaître dans les logs serveur selon votre configuration (niveau de log, hébergeur). En production, définissez une politique de rétention et masquez les données sensibles.

Corpus indexé

Les documents que vous indexez restent sous votre contrôle sur le disque du serveur. Le projet ne les envoie pas à un tiers sauf si vous configurez un LLM cloud (clés API dans .env) : dans ce cas, le fournisseur applique ses propres conditions.

Comptes utilisateurs

Les identifiants et hash de mot de passe sont stockés en base SQLite locale. Utilisez des mots de passe forts et une clé secrète stable (WEBAPP_SECRET_KEY).
