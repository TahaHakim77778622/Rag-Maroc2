Fonctionnalités

Fonctionnalités détaillées

Vue d’ensemble des capacités actuelles du dépôt — utile pour cadrage produit ou fiche projet.

Interface chat professionnelle

Zone de messages, libellés « Vous / Assistant », panneau Sources avec score et lien externe, paramètre k, nouvelle conversation.

Authentification multi-canal

Sessions cookie pour l’UI web ; JWT Bearer pour Streamlit, scripts ou intégrations mobiles.

Pipeline RAG configurable

Expansion de requête (acronymes), pool FAISS élargi, reclassement lexical, prompts orientés listes et citations.

Site vitrine & conformité

Pages Accueil, À propos, FAQ, Confidentialité ; robots.txt pour limiter l’indexation de l’API.

Observabilité minimale

Endpoint /health, logs côté serveur sur les appels /api/ask (nombre de passages renvoyés).

Déploiement local robuste

Script uvicorn recommandé avec --http h11 --loop asyncio pour réduire les soucis natifs sur macOS (torch / FAISS).

Pour les équipes métier

Priorisez des jeux de questions réalistes et mesurez le taux de réponses sourcées correctes avant d’élargir l’audience.

Pour les développeurs

Tout passe par FastAPI : ajoutez middleware, rate-limit, ou reverse-proxy (TLS) sans changer le cœur RAG.
